# Бюро находок

Бесплатный открытый тест новогоднего домашнего квеста для детей 5–13 лет. Редакция 1.5.0-beta.1.

Играть: https://sfycus.github.io/portfolio-sites/buro-nahodok/

Можно играть в браузере без печати или искать бумажные карточки. Новые наборы содержат 36 типов заданий для трёх возрастов. Перед запуском можно попробовать первую загадку и подобрать другой набор. Есть крупный текст, подсказки и разбор вместе со взрослым.

Настройки и прогресс хранятся в браузере игрока. Прежние ссылки сохраняют свои задания и коды карточек. Отзывы: https://t.me/sfycus.

Файлы скопированы из актуальной сборки gift-trail. Авторы фотографий и лицензия указаны в CREDITS.md. Приём оплаты в открытом тесте не включён.
