# Каталог десяти сайтов

Простая статическая витрина для заказчиков: десять концептуальных проектов, фотографии, краткие описания, ссылки на работающие сайты и отдельные репозитории с кодом. Каталог не содержит форм внутреннего согласования.

## Публикация

Структура для одного GitHub Pages репозитория:

```text
portfolio-public/
├── index.html
├── style.css
├── data.js
├── app.js
├── assets/
└── sites/
    ├── nocturne/
    ├── coral-house/
    ├── roam/
    ├── beryl/
    ├── pollen/
    ├── orbit/
    ├── northstar/
    ├── grain/
    ├── frame/
    └── hem/
```

Все десять готовых сайтов уже включены в папку `sites/`. Каталог ссылается на них относительными путями `sites/{slug}/` и потому работает как в локальном предпросмотре, так и на GitHub Pages. Каждый сайт также подготовлен как самостоятельный публичный репозиторий. Имена этих репозиториев указаны в `data.js` в поле `repo`.

`GITHUB_OWNER` в `data.js` указывает на аккаунт `sfycus`. При необходимости его можно заменить другим логином GitHub.

Ссылки «Открыть сайт» ведут на страницы внутри каталога. Ссылки «Исходный код» ведут на соответствующие репозитории `https://github.com/{GITHUB_OWNER}/{repo}`.

Для проверки локально из родительской папки:

```sh
python3 -m http.server 8799
```

Откройте `http://127.0.0.1:8799/`.

Фотографии сохранены локально, авторы и источники указаны в [CREDITS.md](CREDITS.md). Все бизнесы и предложения вымышлены; сайт не должен представлять их как действующих заказчиков.
